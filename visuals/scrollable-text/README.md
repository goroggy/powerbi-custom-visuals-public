# Scrollable Text

Scrollable text box for long Power BI text measures or text columns.

## Features

- Single text field input
- Vertical scrolling
- Preserves line breaks
- Font family, font size, line height, and padding settings
- Text and background color settings
- Simple center/right alignment toggles

## Build

```powershell
npm install
npm run package
```

The packaged `.pbiviz` file is written to `dist/`.
