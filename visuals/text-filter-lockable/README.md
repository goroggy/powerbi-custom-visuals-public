# Text Filter (Lockable)

Microsoft Text Filter fork with one extra behavior: a lock option. When locked, the visual ignores Clear All Slicers-style reset events and keeps its current filter.

## Package

- `../../artifacts/textFilterLockableEG7291A0B1C2D3E4F5.2.3.0.0.pbiviz`

## Build

```powershell
npm install
npm run package
```
